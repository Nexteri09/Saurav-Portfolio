# Saurav Karande — UX/UI Designer Portfolio

Personal product design portfolio of Saurav Karande, featuring:
- **The Living Horizon**: Dynamic 8-layer panoramic mountain strata that reacts seamlessly to scroll and mouse orientation.
- **SubSync Case Study**: In-depth UX/UI product design showcase for subscription management with high-resolution slide modal presentation.
- **How I Work**: Unboxed four pillars detailing AI-assisted workflows, attention to detail, problem-solving, and continuous learning.
- **Editorial Typography**: Crafted using Outfit and Plus Jakarta Sans with human-crafted unboxed aesthetics.
- **Contact Spread**: Minimal direct channels and unboxed communication form.

## Tech Stack
- Vanilla HTML5 / CSS3 / JavaScript (ES6+)
- Zero external frontend frameworks or heavy dependencies
- Responsive across all modern desktop and mobile viewports
